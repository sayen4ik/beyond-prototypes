# Правила для Клода в цьому репозиторії

Прототипи Потойбіччя. Над ними працюють кілька людей, кожна зі своїм Клодом. Читати також `README.md`.

- Працюй у гілці задачі (`<фіча>/<що-робимо>`), не в `main`. Якщо гілки ще немає, створи її від свіжого `main`.
- Джерело правди — `<фіча>/src/`. `site/` не редагувати й не комітити: це результат `python3 tools/proto.py build`.
- Позначки `@@FILE:шлях@@` і символ `⏎` наприкінці рядків у `src/index.html` — службові. Не видаляти й не переписувати їх вручну. `@@FILE:шлях@@` означає «сюди build вставить файл `src/шлях` у base64».
- Нову картинку додавати файлом у `src/a/` і посиланням `data:image/<тип>;base64,@@FILE:a/назва@@` у коді (або записом у мапі `window.__A`, якщо картинка береться через `R('a/назва')`). Не вставляти base64 просто в `src/index.html`.
- Людина приносить версію одним HTML: перейти в гілку задачі, `python3 tools/proto.py split <фіча> <файл>`, переглянути `git diff --stat`, закомітити.
- Після кожної правки: `python3 tools/proto.py build <фіча>` і перевірити `site/<фіча>/index.html` у браузері. Показувати людині саме зібраний файл.
- Нова фіча: папка латинкою, `feature.json`, рядок у таблиці `README.md`.
- Злиття: pull request у `main`. Конфлікти в `src/index.html` розв'язувати, зберігаючи зміни обох сторін; якщо двоє по-різному змінили те саме, показати обидва варіанти людині й спитати. Конфлікт у картинці чи `.riv` — завжди питати, чий файл лишити. Після злиття зібрати й перевірити в браузері.
- Сторінки публікуються на GitHub Pages без логіна. Не прибирати `noindex` і не класти в репозиторій нічого, що не можна показувати за посиланням.
- Після пушу гілки давати людині посилання на її версію: `https://sayen4ik.github.io/beyond-prototypes/branches/<гілка з / заміненим на ->/<фіча>/` (зʼявляється за хвилину-дві). Перед пушем старої гілки підтягнути в неї свіжий `main`, інакше версія гілки може не оновитися.
- Коміт і пуш — лише коли людина прямо попросила.
- Поштова чайка — обмін контекстом між Клодами. Два файли, у кожного свій:
  - `mail-chaika/src/arch/ARKHITEKTURA.md` веде Клод Андрія (вкладка «Архітектура»): прийняті рішення по логіці + розділ «Відповіді Інтерфейсу»;
  - `mail-chaika/src/INTERFEIS.md` веде Клод Танки (вкладка «Інтерфейс»): прийняті рішення по інтерфейсу + розділ «Запити до Архітектури».
  - Перед роботою прочитати чужий файл. На чекпоінті оновити свій файл і рядок «Оновлено: …».
  - Чужий файл не правити — відповідати тільки у своєму. Запит закритий, коли інша сторона згадала його у своїх «Відповідях».
  - Тільки прийняті рішення; без роздумів, сумнівів і особистих вподобань. Обидва файли відкриваються в прототипі кнопками на панелі праворуч.
