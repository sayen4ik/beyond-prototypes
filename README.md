# Прототипи Потойбіччя

Спільний репозиторій прототипів. Кожна фіча — окрема папка. Працюємо в гілках, готове зливаємо в `main`.

## Фічі
| Папка | Що це | Хто веде | Стан |
|---|---|---|---|
| [`idol-halls/`](idol-halls) | Зала культу і Зала Змагань: прожектор на лідері, Rive-риба | Танка, Андрій | у роботі |

## Що де лежить
- `<фіча>/src/index.html` — код сторінки (розмітка, стилі, скрипти). Правимо тут.
- `<фіча>/src/a/` — картинки окремими файлами; `<фіча>/src/bin/` — Rive-файли й рушій Rive.
- `<фіча>/feature.json` — назва, опис, хто веде і стан: з цього збирається картка на сторінці-розвіднику.
- `tools/proto.py` — збирання й розкладання; `tools/hub.html` — шаблон сторінки-розвідника.
- `site/` — зібраний результат. У репозиторій не потрапляє.

У `src/index.html` на місці кожної картинки стоїть позначка на кшталт `@@FILE:a/header.webp@@`, тому сам він у браузері не відкривається: дивитись треба зібраний файл.

## Подивитись
```bash
python3 tools/proto.py build
```
Відкрити `site/index.html` — це сторінка-розвідник з картками всіх фіч. Кожен прототип — один файл `site/<фіча>/index.html`, його можна надіслати окремо.

## Принести версію, яка існує як один HTML
```bash
python3 tools/proto.py split idol-halls шлях/до/мого.html
```
Команда перезаписує `idol-halls/src/` вмістом цього HTML і перевіряє, що з частин збирається той самий файл. Робити у своїй гілці, не в `main`.

## Додати нову фічу
Створити папку з назвою латинкою, покласти в неї `feature.json` (за зразком `idol-halls/feature.json`), розкласти HTML командою `split` і додати рядок у таблицю вище.

## Як працюємо
1. Гілка на задачу: `idol-halls/prozhektor`, `mail-chaika/konvert`. У `main` напряму не пишемо.
2. Готову гілку зливаємо в `main` через pull request на GitHub.
3. Якщо двоє змінили те саме місце, Клод покаже обидва варіанти й спитає, який лишити.

## Посилання
Після злиття в `main` GitHub сам збирає все й публікує на GitHub Pages (`.github/workflows/pages.yml`). Сторінки відкриваються без логіна всім, хто має адресу; на кожній стоїть позначка `noindex`, яка просить пошуковики їх не індексувати.
